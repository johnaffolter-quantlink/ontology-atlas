## 2026-09-24 — Atlas travels as a Claude Code plugin built from the verified bundle

**Why**: the owner asked for Atlas as a lightweight plugin that travels with agents. Nothing carried the server and its write discipline into sessions in other repositories, and without a vault the server exited, leaving the agent no tools and no reason.
**Prior**: upholds 2026-09-11 "Atlas enters the MCP ecosystem as a release bundle" and 2026-07-27 "npm publish plan is dropped".
**Decision**: `plugins/ontology-atlas/` holds only manifest, `.mcp.json`, a dependency-free launcher and the `atlas-orient`/`atlas-sync` skills; `pnpm plugin:build` unpacks the server from the verified MCPB into `.tmp/atlas-plugin` with a marketplace, so no server copy is in Git. The launcher resolves `OATLAS_VAULT`, `./atlas`, `./docs/ontology` to an absolute path, else serves one read-only `atlas_status` tool and never creates a vault. Skills carry the write contract; no permissions are granted in advance. The build fails closed unless `claude plugin validate` and both install cases pass. App embedding is out of scope.
**Dissent**: evidence review wanted a real-install probe first; the build's install proofs and `claude --plugin-dir … mcp list` connecting in both cases stand in. Steward: skill text is not a guard; host approval and `OATLAS_READ_ONLY`/`OATLAS_WRITE_CONSENT` are.
**Falsifier**: an install resolves a vault other than the project's, a write lands without host approval, or within 90 days nobody outside the owner installs it.
**Owner**: repository owner
